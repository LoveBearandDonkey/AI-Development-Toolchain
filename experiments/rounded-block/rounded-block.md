# 计算主题装饰图形

[打开圆角长方体预览](rounded-block.html)

算子队列的联想主要来自一组几何关系。各块横截面相近，沿同一方向排布，长短和间距有变化，端面清晰可见。把这些关系保留在装饰图形中，熟悉性能泳道的读者就有机会认出这种节奏。单块原型先确定形体、材质和视角。

## 四张图的共同规律

| 参考图 | 配色与过渡 | 形体与边缘 |
| --- | --- | --- |
| `e7ad0618…` | 青蓝色斑铺在薄荷绿主体上，近端沉到深青绿。部分块用接近背景明度的灰白留出间隔。 | 变长的块仍保持相近的截面。青蓝与绿沿倒角转到侧面，轮廓处还有一层很淡的青色。 |
| `23507849…` | 嫩绿反复出现在外缘，米黄、蜜桃和暖黄填在内部。近端照片里的蓝和棕提供局部深色。 | 前景由尺寸相近的短块组成。可见端面有内嵌图像，图像边缘随倒角淡入主体。 |
| `85b77cba…` | 淡粉紫打底，左中用蓝紫色斑，右中用灰梅紫色斑，中间保留浅色间隔。近端为深海军蓝。 | 单条细长块形最清楚。顶部与侧面连成连续亮度，远端转角提亮，外缘带淡粉紫。 |
| `14dccabf…` | 杏橙与金黄做底，奶白高光和赤陶暗带斜穿块体。相近色温让切换看起来平缓。 | 长块和短块共用圆角厚度。焦内块的外轮廓清楚，柔化集中在内部带状过渡和倒角。 |

参考图的背景接近白灰，主体每次只让一两块颜色占据较高饱和度。大小不一的色斑同时沿长轴和截面变化，因此色带在转角处会弯折。轮廓附近有很窄的同系色和明度变化，能在浅底上维持形状。雾紫、青绿、嫩绿蜜桃和暖橙以下列 JPEG 局部取样为起点，再调亮底色和提亮色以适应单块构图。坐标以原图左上角为原点。

| 色系 | 局部取样 |
| --- | --- |
| 雾紫 | 蓝紫 `#AEB0FA`（534, 532），灰梅紫 `#84668C`（751, 470），深蓝 `#0D233B`（330, 639） |
| 青绿 | 淡薄荷 `#9EE5C3`（791, 292），青蓝 `#4B9AB9`（627, 393），深青绿 `#427962`（584, 411） |
| 嫩绿蜜桃 | 暖黄 `#FCC865`（767, 278），蜜桃 `#FACDC8`（560, 508），嫩绿 `#C5EDAE`（630, 485） |
| 暖橙 | 金杏 `#FAB95F`（997, 247），橙色 `#ED9057`（660, 327），暖浅褐 `#E3B198`（778, 251） |

另外四套沿用浅底、局部色斑和较深端面的配色方式。冷蓝从冰蓝过渡到钢蓝，薄荷从嫩叶绿过渡到灰绿，雾粉从浅粉过渡到莓红，暖铜从浅铜过渡到焦棕。

「随机混色与自定义」首次打开会从八套配色中随机选三套。点击色圈选取 `2–8` 色，选中色圈带高亮外环。直接拖动色圈调整顺序，键盘可按住 `Shift` 加左右方向键移动。「重新随机」按当前所选数量生成新组合。选中的颜色按色圈从左到右的顺序混合，横放时从近端排到远端，立放时从底端排到顶端。色域扩散控制相邻色的过渡宽度。

「动态」每轮将八套配色随机排列。每色停留 `1.8 s`，接着在 `1 s` 内让新色从画面右侧向左推进。推进开始较快，接近结束时逐渐减速。边界平滑过渡，PNG 导出取点击时的配色帧。

## 绘制方法

| 层 | 原型做法 | 可调参数 |
| --- | --- | --- |
| 几何 | 用圆角盒的符号距离场（SDF）描述三维表面。先定义缩小后的盒体，再向外扩一个统一半径，平面之间自然接成圆弧。 | 默认长 × 宽 × 厚为 `4.60 × 1.66 × 1.00`，长度和宽度均可调 `1–5`，厚度可调 `1–2`。圆角百分比乘最短边的一半，默认半径约 `0.36`。 |
| 投影 | 从正交相机向形体发射光线，按距离场步进求交。「长」为斜向横放，「高」将块体旋转 `90°` 立起。 | 默认为「长」，水平和俯仰转角范围均为 `−60°` 至 `60°`，默认分别为 `44°` 和 `32°`。预览与导出会为两种姿态留出边距。 |
| 色斑 | 在物体坐标中叠加两个宽的高斯色斑，分别控制中段和远段。长轴两端共用同一深色规则，色斑和端面色都沿倒角过渡。 | 色域扩散控制高斯范围与端面过渡宽度。`base`、`middle`、`far` 和 `end` 控制各区域颜色，`cap` 控制两端的深色强度。 |
| 明暗 | 按表面法线计算低对比的漫反射和底缘反光，远端额外提亮。 | `light` 控制受光和反光的颜色。 |
| 轮廓着色 | 从投影后的轮廓向内估算像素距离，把轮廓色按距离平滑衰减，只混合形体内的颜色。 | 强度控制边缘的混色比例。厚度控制颜色向内延伸的距离，范围 `0–64 px`，默认 `32 px`，以 `720 × 450` 为基准，随渲染分辨率等比缩放。 |
| 外缘 | 将盒体核心的正交投影向外扩一个圆角半径，用浏览器光栅化的像素覆盖率平滑透明度。轮廓、表面位置和光照在配色之间复用。 | 预览按实际显示像素渲染，最高 `1440 × 900`。连续调整滑杆时用较小画布保持跟手，停下后恢复高分辨率。透明 PNG 固定以 `1440 × 900` 重新渲染。 |

这些配色以可调参数呈现。带照片的两张参考图在单块原型里用纯色端面转译，材质只依赖尺寸、视角、色彩、光照和形体边缘。交互参数在 [rounded-block.js](rounded-block.js)，渲染与动态配色规则在 [共享渲染器](../../assets/rounded-block-renderer.js)。

后续组合成装饰图案时，可以保持截面、圆角和光向一致，让长短、间隔和少量错位形成队列的联想。大片留白能让这组形体作为页面配图独立成立。
